# Store-template defaults

These are the template's supported starting boundaries. Each new owner confirms business choices; sample values are never an approved policy.

| Area               | Starting contract                                                                                                                                                                                                                                                                                                                                                      |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Audience           | Owners work with an agent. The agent handles code and authorized admin work; owners sign in, provide facts and choose designs.                                                                                                                                                                                                                                         |
| Isolation          | Separate repository, domain, deployment, Supabase database/Auth, private artwork Blob, public mockup Blob, Printify account/shop and Stripe account per store. Use a separate Printify account per brand; a shared account requires an explicit owner-accepted exception for account-wide access and quotas. Verify dedicated existing resources before creating more. |
| Initial model      | Next Level 6210 (blueprint 1317), provider 99 for per-design colors, with reviewed sizes, colors, placement and price rule. Other provider recipes need separate compatibility work. The first product uses an explicit verified app draft recipe; the design-page button and proposals subsequently copy a published model.                                           |
| Commerce           | USD and standard shipping to the 50 US states plus DC. New regions/currencies/discount models may need code changes, not just configuration.                                                                                                                                                                                                                           |
| Public identity    | `src/lib/store-config.ts`, theme and approved public assets. Setup and policy confirmation start false. No original brand fallback or product inventory.                                                                                                                                                                                                               |
| Owner choices      | Name, audience, design, domain, time zone, weekly feature cadence, pricing, shipping charges, delivery commitments, support, policies and permitted agent decisions. Never infer tax registrations or business verification details.                                                                                                                                   |
| Creative setup     | Offer storefront, logo, favicon and palette concepts. Generate the agreed scope and preserve selected originals. Shirt art lives in the private library.                                                                                                                                                                                                               |
| Private library    | Fresh admin setup and empty library. Permanent design numbers, immutable revisions, personal pinned favorites and scoped agent grants belong to this store.                                                                                                                                                                                                            |
| Product uniqueness | One binding per shop, canonical design and stable model. Reconcile uncertain creation; new requests/colors/revisions are not permission for duplicate same-model listings.                                                                                                                                                                                             |
| Publishing         | Draft by default. Authorized Printify Publish creates a hidden store snapshot; complete garment/category profiles before showing or scheduling it. Verify public mockups and exact approved artwork derivatives.                                                                                                                                                       |
| Activation         | Real fulfillment, optional marketing and alerts start off. Worker schedules are supplied as an example and must be configured and verified for the chosen host. Reuse actual owner authorization; uncovered live purchases, new costs and releases need a concrete decision.                                                                                           |
| Progress           | Ignored `.store-setup.local.json` contains non-secret answers/status/evidence. `.worktreeinclude` copies that file only as a creation-time snapshot; reconcile it at handoff. Secrets stay in local/deployment secret storage or private grant files.                                                                                                                  |
| Evidence           | Configuration, local tests, sandbox payment, signed callbacks, production release, payment capture, manufacturing, samples, merchant approval and event receipt are separate facts.                                                                                                                                                                                    |

This is a single-store architecture. A marketplace, shared multi-merchant database, Stripe Connect platform or Printify OAuth platform is a separate scope. This template provisions a fresh store; importing another store’s operational database is unsupported.
