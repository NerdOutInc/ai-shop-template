# Weekly store heroes

Turn a verified product lineup into a reviewable pair of homepage compositions. The product is evidence; the scenery is the creative playground.

This folder is portable. It does not include an image generator, store credentials, a scheduler or a particular brand's artwork. Discover available image, filesystem and browser tools. Read the target project's instructions and current hero implementation before choosing dimensions or performing a store action. No sibling skill is required; if a garment-photography skill is available, it can supply the more detailed cloth-compositing method.

## Start with the release and the output contract

Read [release and integration](references/release-and-integration.md) when identifying products or saving a hero. Confirm the exact scheduled instant in the store's named time zone, product/variant/color identities, original print revision and current provider mockups. A historic receipt or public newest-product list is not the current lineup.

For a concept request, preserve the requested count: **N directions with desktop and mobile means 2N complete review images**. A contact sheet, unfinished background or automatic crop is not a second composition. Creating hero concepts does not create new printable designs or authorize publishing the products.

Read the receiving renderer/upload contract for dimensions, crops, safe areas, limits, link areas and accessible content. If there is no hero runtime, deliver an explicitly proposed composition contract and private review files. Do not invent an admin editor or claim the images are scheduled.

## Calibrate before generating the collection

Read [garment fidelity](references/garment-fidelity.md). Prepare one measured garment layer per product/color from its current reference and the original approved high-resolution PNG. Record neckline gap, horizontal center, print width/height and lower-fabric clearance separately. Inspect the first finished pair at native size and phone width before generating the remaining requested directions; correct its calibration first.

Keep calibrated merchandise outside whole-poster generation. Generate scenery and lettering separately where possible. Preserve the approved garment construction and original ink; uniform garment transforms are different from changing the print on the garment. Code-based image edits require whatever explicit opt-in the active image tool demands. If unavailable, report that constraint and use a supported workflow without pretending the artwork stayed pixel-exact.

## Compose, review and retain

Read [composition and review](references/composition-and-review.md) for art direction, paired-view design and final checks. Include current, verified copy only. Preserve the owner's brand preferences; this skill does not prescribe a price, shipping offer, garment type, model cast or ban on people.

Number directions consistently, show each desktop/mobile pair together and expose full-resolution files. Use an available concept/gallery tool when helpful; private review assets need the owner's intended access level. The skill does not require a particular hosting service.

After selection, refine only what needs changing. Measure click regions from final pixels using [the layout helper](references/layout-helper.md). Independently inspect the final exact files for product fidelity, layout, copy and links; an uncertain garment placement is unfinished, not a pass. If delegation is available and the user authorized it, give a reviewer the source reference, original art, calibration and final image without the author's pass/fail conclusion.

Keep the selected final pair and reusable image inputs in the host's private asset store, with prompts, geometry, hashes and a release receipt for replay. Read [retention and replay](references/retention-and-replay.md). Follow the host's storage policy: operational artwork, final uploads and model references stay out of Git by default; commit only permitted, non-sensitive instructions and metadata. Rejected batches stay in ignored working storage or an approved private archive. Preserve inputs until the selected package and any agreed archive have been restored and checked.

A complete handoff states the count delivered, selection, exact files, validation evidence and actual state: awaiting selection, private draft, scheduled, or verified live. Saving an archive, uploading an image and scheduling a hero are separate outcomes.
