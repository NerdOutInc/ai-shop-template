01 Copy this into your agent

Use https://github.com/NerdOutInc/ai-shop-template/blob/main/setup.md to help me start my own clothing shop.

Paste into Codex desktop or another coding agent with access to your files and terminal. It will guide you through your brand, designs, accounts, and first products.

You’re starting a shop. The setup manual is your agent’s homework.

How do I connect my accounts?

Ask Codex to help connect GitHub, Supabase, and Vercel. It can find the available plugins and guide you through sign-in.

To do it yourself, open the plugin directory, find the provider, install its plugin, and complete its connection prompts. Start a new chat if the tools don’t appear.

A plugin isn’t required for every service. Your agent can also use the provider’s command-line tools or an authenticated browser. It checks what’s available and gives you only the steps it needs you to do.

You handle sign-ins, verification, and billing approval. Enter passwords and keys only in the secure location your agent prepares, never in chat.

02 What you’ll need

  • An AI coding agent + GitHub

    Use a coding agent with access to your files and terminal, plus a GitHub account for your shop’s own repository.

  • Vercel + Supabase accounts

    Vercel hosts your shop; Supabase handles its database and admin sign-in. No projects to create in advance. Your agent can create them once connected, with your choices and cost approval.

  • Printify + Stripe, before selling

    Printify prints and ships. Stripe takes payments. Your agent helps with setup; you complete business verification and billing.

Plan for hosting and service costs. A selling store needs Vercel Pro or Enterprise for scheduled jobs. Your agent reviews costs before activation.

What’s supported to start?

The built-in workflow starts with Next Level 6210 tees, Printify provider 99, USD, and standard shipping to the 50 US states plus DC. Other products or markets may need additional work.

Your agent also helps configure artwork storage, admin email, and local setup tools. Image generation needs an available image tool. A custom domain and marketing tools can come later.
